## ADDED Requirements

### Requirement: 基金搜索
系统 SHALL 支持按基金名称或代码搜索基金。

#### Scenario: 按名称搜索
- **WHEN** 用户输入"沪深300"
- **THEN** 系统显示所有名称包含"沪深300"的基金列表

#### Scenario: 按代码搜索
- **WHEN** 用户输入"000300"
- **THEN** 系统显示代码为"000300"的基金

#### Scenario: 搜索结果为空
- **WHEN** 用户输入不存在的基金名称
- **THEN** 系统显示"未找到相关基金"提示

### Requirement: 基金排行榜
系统 SHALL 显示基金排行榜，支持按类型、收益率、规模等维度筛选和排序。

#### Scenario: 查看股票型基金排行
- **WHEN** 用户选择"股票型"类型
- **THEN** 系统显示股票型基金按近1周收益率降序排列

#### Scenario: 切换排序维度
- **WHEN** 用户选择"近1月收益率"排序
- **THEN** 系统重新排序并显示结果

#### Scenario: 分页加载
- **WHEN** 用户滚动到列表底部
- **THEN** 系统加载下一页数据

### Requirement: 基金详情页
系统 SHALL 显示基金详细信息，包括基本信息、净值走势、持仓、基金经理、公告等。

#### Scenario: 查看基金基本信息
- **WHEN** 用户点击基金卡片
- **THEN** 系统显示基金名称、代码、类型、规模、成立日期等信息

#### Scenario: 查看净值走势图
- **WHEN** 用户在基金详情页选择"近1月"
- **THEN** 系统显示近1月的净值走势图

#### Scenario: 查看基金经理信息
- **WHEN** 用户点击基金经理名称
- **THEN** 系统显示基金经理详细信息和管理的其他基金

### Requirement: 基金对比
系统 SHALL 支持最多4只基金的对比功能。

#### Scenario: 添加对比基金
- **WHEN** 用户在基金详情页点击"添加对比"
- **THEN** 系统将该基金添加到对比列表

#### Scenario: 查看对比结果
- **WHEN** 用户点击"开始对比"
- **THEN** 系统并排显示所选基金的关键指标对比

#### Scenario: 超过对比上限
- **WHEN** 用户尝试添加第5只基金到对比列表
- **THEN** 系统提示"最多对比4只基金"

### Requirement: 基金数据缓存
系统 SHALL 缓存基金数据到本地，减少 API 调用次数。

#### Scenario: 首次查看基金详情
- **WHEN** 用户首次查看某基金详情
- **THEN** 系统从 API 获取数据并缓存到 localStorage

#### Scenario: 再次查看基金详情
- **WHEN** 用户在缓存有效期内再次查看该基金
- **THEN** 系统从缓存读取数据，不调用 API
